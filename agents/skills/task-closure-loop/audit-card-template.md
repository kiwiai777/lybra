# 审计卡模板(executor 自产用;只填 <> 变量,其余原样)

> 用法:执行者完成任务后复制本模板,替换全部 `<>` 占位;**不得增删改其余文字**
> (尤其"准绳"行——审计范围由原卡定义,不由本卡定义)。
> **⚠️ 原卡路径必须从你冷启动 kickoff 消息原文逐字抄录**(kickoff 恒含所claim的卡路径);
> **禁止凭记忆重构**——长会话压缩后记忆重构=幻觉路径(实案 2026-07-25:执行者编造不存在
> 的被审卡路径,auditor ENOENT 阻塞)。kickoff 已不可见(被压缩)→ block-and-report 问,不猜。

```markdown
# 任务卡:<原卡号>R — 独立审计:<原卡标题>(第 <N> 轮)

- **执行角色**: <审计角色,默认 lybra-auditor>(pi,`/claim` 本卡)
- **被审卡**: `<原执行卡路径>`
  ★ **审计准绳 = 上述原卡的验收断言与红线原文;本卡仅为指路牌,不构成准绳**
- **交付物位置**: <路径清单>
- **执行者 return**: <位置(会话内/文件路径)>
- **复审轮次**: 第 <N> 轮(首轮=1;本卡已历 <M> 轮 FAIL;≥2 轮 FAIL 后仍不 PASS
  → auditor 停审报顾问仲裁)
- **本轮重点**: <首轮填"全量";复审轮粘贴上轮 F-* 清单原文 + "回归抽查">
- **程序引用**: `audit-independent-evidence`(全程)/ `write-return`(收尾)/
  `block-and-report`(遇阻)
- **车道**: 读=被审系统与两仓;**唯一写出口** = `<审计报告路径,不确定就写 v4 默认:~/projects/lybra/task_cards/<原卡号>/AUDIT-REPORT-<原卡号>.md>`
```
